# The Tired Dark Lord: A 100-Word Villain Monologue

A make.fun entry for [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/c/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb).

`main.py` (pure Python standard library, deterministic) writes one
monologue of exactly 100 words to `/output/entry.txt`. The speaker is
Kevin, dark lord of one tower for nine hundred years. His tiredness is
never announced: it lives in the lost thread, the pauses, and the
paperwork he keeps deflecting to — permits for the moat, forms for the
curse, three copies for the ravens, who eat the copies. The sting lands
in the last line.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Two runs write byte-identical output. The program asserts its own gate
before writing: exactly 100 words and 1–600 characters.
